`@piplup/rhf-adapters` connects UI components to [React Hook Form](https://react-hook-form.com)
without a `Controller` for every field. It's split into subpaths, one per UI library, and you
install only the libraries for the subpaths you import.

## Install the package

Install the adapters with `@piplup/rhf-core`, which they're built on, and React Hook Form:

```package-install
@piplup/rhf-adapters @piplup/rhf-core react-hook-form
```

Then add the peer dependencies for each subpath you use, from the sections below.

| Subpath                                                        | Adapts                                                                    | Also install                                               |
| -------------------------------------------------------------- | ------------------------------------------------------------------------- | ---------------------------------------------------------- |
| [`/html`](#html)                                               | Native input, textarea, label, button and helper text                     | Nothing                                                    |
| [`/mui-material`](#mui-material)                               | TextField, Select, Autocomplete, Checkbox, Radio, Switch, Slider and more | `@mui/material`, `@emotion/react`, `@emotion/styled`       |
| [`/mui-x-date-pickers`](#mui-x-date-pickers)                   | Date, time and date-time pickers, fields, calendars and clocks            | The MUI packages, `@mui/x-date-pickers` and a date library |
| [`/react-number-format`](#react-number-format)                 | NumericFormat, PatternFormat, NumberFormatBase                            | `react-number-format`                                      |
| [`/mui-chips-input`](#mui-chips-input)                         | MuiChipsInput                                                             | The MUI packages and `mui-chips-input`                     |
| [`/mui-color-input`](#mui-color-input)                         | MuiColorInput                                                             | The MUI packages and `mui-color-input`                     |
| [`/mui-file-input`](#mui-file-input)                           | MuiFileInput                                                              | The MUI packages and `mui-file-input`                      |
| [`/mui-one-time-password-input`](#mui-one-time-password-input) | MuiOtpInput                                                               | The MUI packages and `mui-one-time-password-input`         |
| [`/mui-tel-input`](#mui-tel-input)                             | MuiTelInput                                                               | The MUI packages and `mui-tel-input`                       |

Import from the subpath, not from `@piplup/rhf-adapters` itself. The root entry point has no
components or hooks, and each subpath only loads its own UI library.

## html

Native `input`, `textarea`, `label` and `button` elements need nothing beyond the packages above:

```tsx
import { HtmlInputElement, HtmlTextareaElement } from '@piplup/rhf-adapters/html';
```

Start with [HtmlInputElement](/docs/rhf-adapters/html/components/html-input-element), which covers
every input type from text to file.

## mui-material

```package-install
@mui/material @emotion/react @emotion/styled
```

```tsx
import { MuiTextFieldElement, MuiSelectElement } from '@piplup/rhf-adapters/mui-material';
```

Start with [MuiTextFieldElement](/docs/rhf-adapters/mui-material/components/mui-text-field-element),
or read [Using MUI with React Hook Form](/docs/react-hook-form-mui) for a full form.

## mui-x-date-pickers

Install MUI, the date pickers and the date library you want the pickers to use:

```package-install
@mui/material @emotion/react @emotion/styled @mui/x-date-pickers
```


Start with [MuiXDatePickerElement](/docs/rhf-adapters/mui-x-date-pickers/components/mui-x-date-picker-element),
or read [Date pickers with React Hook Form](/docs/react-hook-form-date-picker) for loading,
submitting and validating dates.

## react-number-format

This subpath wraps `react-number-format` directly and doesn't need MUI:

```package-install
react-number-format
```

```tsx
import {
  NumericFormatElement,
  PatternFormatElement,
} from '@piplup/rhf-adapters/react-number-format';
```

To render the formatted input as an MUI `TextField`, install the MUI packages too and pass
`customInput={TextField}`. Start with
[NumericFormatElement](/docs/rhf-adapters/react-number-format/components/numeric-format-element).

## Supported versions

`@piplup/rhf-adapters` 5 accepts these versions of its peer dependencies. Every UI library is
optional, so only the ones behind the subpaths you import need to be installed.

| Package                       | Versions      |
| ----------------------------- | ------------- |
| `react`                       | 19            |
| `react-hook-form`             | 7.65 or later |
| `@mui/material`               | 6 to 9        |
| `@mui/x-date-pickers`         | 8 to 9        |
| `react-number-format`         | 5.4.2 to 5    |
| `mui-chips-input`             | 4.0.1 to 9    |
| `mui-color-input`             | 5.0.1 to 9    |
| `mui-file-input`              | 6 to 9        |
| `mui-one-time-password-input` | 5 to 7        |
| `mui-tel-input`               | 7 to 11       |
