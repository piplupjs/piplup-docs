`MuiXDatePickerElement` supports all standard props of the MUI X DatePicker component, along with additional adapter-specific props. For a complete list of available DatePicker properties, refer to the MUI X Date Pickers [API documentation](https://mui.com/x/api/date-pickers/date-picker/).

> The `ref` is forwarded to the underlying `<DatePicker />` component.

## Notes

- For custom picker UIs, build on `useMuiXDatePickerAdapter`.
