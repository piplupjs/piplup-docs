`MuiXDesktopDatePickerElement` supports all standard props of the MUI X DesktopDatePicker component, along with additional adapter-specific props. For a complete list of available DesktopDatePicker properties, refer to the MUI X Date Pickers [API documentation](https://mui.com/x/api/date-pickers/desktop-date-picker/).

> The `ref` is forwarded to the underlying `<DesktopDatePicker />` component.

## Notes

- For custom desktop date pickers, build on `useMuiXDesktopDatePickerAdapter`.
