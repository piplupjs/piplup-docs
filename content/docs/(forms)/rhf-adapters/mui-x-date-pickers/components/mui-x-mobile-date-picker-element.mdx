`MuiXMobileDatePickerElement` supports all standard props of the MUI X MobileDatePicker component, along with additional adapter-specific props. For a complete list of available MobileDatePicker properties, refer to the MUI X Date Pickers [API documentation](https://mui.com/x/api/date-pickers/mobile-date-picker/).

> The `ref` is forwarded to the underlying `<MobileDatePicker />` component.

## Notes

- For custom mobile date pickers, build on `useMuiXMobileDatePickerAdapter`.
