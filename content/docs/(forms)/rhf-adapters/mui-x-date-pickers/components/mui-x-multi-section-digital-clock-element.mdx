## Props

<AutoTypeTable path="content/docs/props.ts" name="MuiXMultiSectionDigitalClockElementProps" cwd />

`MuiXMultiSectionDigitalClockElement` supports all standard props of the MUI X MultiSectionDigitalClock component, along with additional adapter-specific props. For a complete list of available MultiSectionDigitalClock properties, refer to the MUI X Date Pickers [API documentation](https://mui.com/x/api/date-pickers/multi-section-digital-clock/).

> The `ref` is forwarded to the underlying `<MultiSectionDigitalClock />` component.

## Notes

- For custom segmented clock UIs, build on `useMuiXMultiSectionDigitalClockAdapter`.
