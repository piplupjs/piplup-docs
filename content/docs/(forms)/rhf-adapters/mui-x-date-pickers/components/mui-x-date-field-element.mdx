`MuiXDateFieldElement` supports all standard props of the MUI X DateField component, along with additional adapter-specific props. For a complete list of available DateField properties, refer to the MUI X Date Pickers [API documentation](https://mui.com/x/api/date-pickers/date-field/).

> The `ref` is forwarded to the underlying `<DateField />` component.

## Notes

- For custom date fields, build on `useMuiXDateFieldAdapter`.
