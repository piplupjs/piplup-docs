`MuiXDesktopTimePickerElement` supports all standard props of the MUI X DesktopTimePicker component, along with additional adapter-specific props. For a complete list of available DesktopTimePicker properties, refer to the MUI X Date Pickers [API documentation](https://mui.com/x/api/date-pickers/desktop-time-picker/).

> The `ref` is forwarded to the underlying `<DesktopTimePicker />` component.

## Notes

- For custom desktop time pickers, build on `useMuiXDesktopTimePickerAdapter`.
