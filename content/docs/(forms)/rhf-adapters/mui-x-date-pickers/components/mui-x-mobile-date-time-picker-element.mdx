```tsx
import { MuiXMobileDateTimePickerElement } from "@piplup/rhf-adapters/mui-x-date-pickers";
```

`MuiXMobileDateTimePickerElement` supports all standard props of the MUI X MobileDateTimePicker component, along with additional adapter-specific props. For a complete list of available MobileDateTimePicker properties, refer to the MUI X Date Pickers [API documentation](https://mui.com/x/api/date-pickers/mobile-date-time-picker/).

> The `ref` is forwarded to the underlying `<MobileDateTimePicker />` component.

## Notes

- For custom mobile date-time pickers, build on `useMuiXMobileDateTimePickerAdapter`.
