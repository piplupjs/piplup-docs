`MuiXYearCalendarElement` supports all standard props of the MUI X YearCalendar component, along with additional adapter-specific props. For a complete list of available YearCalendar properties, refer to the MUI X Date Pickers [API documentation](https://mui.com/x/api/date-pickers/year-calendar/).

> The `ref` is forwarded to the underlying `<YearCalendar />` component.

## Notes

- For custom year calendars, build on `useMuiXYearCalendarAdapter`.
