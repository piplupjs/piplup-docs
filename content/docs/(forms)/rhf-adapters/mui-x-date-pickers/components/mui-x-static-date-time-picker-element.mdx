`MuiXStaticDateTimePickerElement` supports all standard props of the MUI X StaticDateTimePicker component, along with additional adapter-specific props. For a complete list of available StaticDateTimePicker properties, refer to the MUI X Date Pickers [API documentation](https://mui.com/x/api/date-pickers/static-date-time-picker/).

> The `ref` is forwarded to the underlying `<StaticDateTimePicker />` component.

## Notes

- For custom static date-time pickers, build on `useMuiXStaticDateTimePickerAdapter`.
