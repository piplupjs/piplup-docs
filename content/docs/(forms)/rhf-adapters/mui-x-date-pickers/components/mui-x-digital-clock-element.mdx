`MuiXDigitalClockElement` supports all standard props of the MUI X DigitalClock component, along with additional adapter-specific props. For a complete list of available DigitalClock properties, refer to the MUI X Date Pickers [API documentation](https://mui.com/x/api/date-pickers/digital-clock/).

> The `ref` is forwarded to the underlying `<DigitalClock />` component.

## Notes

- For custom clock UIs, build on `useMuiXDigitalClockAdapter`.
