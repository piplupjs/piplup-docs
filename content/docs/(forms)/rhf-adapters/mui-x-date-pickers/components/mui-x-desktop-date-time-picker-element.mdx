`MuiXDesktopDateTimePickerElement` supports all standard props of the MUI X DesktopDateTimePicker component, along with additional adapter-specific props. For a complete list of available DesktopDateTimePicker properties, refer to the MUI X Date Pickers [API documentation](https://mui.com/x/api/date-pickers/desktop-date-time-picker/).

> The `ref` is forwarded to the underlying `<DesktopDateTimePicker />` component.

## Notes

- For custom desktop date-time pickers, build on `useMuiXDesktopDateTimePickerAdapter`.
