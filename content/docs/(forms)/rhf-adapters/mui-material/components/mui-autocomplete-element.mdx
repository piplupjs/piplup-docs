`MuiAutocompleteElement` is MUI's `Autocomplete` connected to React Hook Form. It stores the
selected option, or an array of options with `multiple`, and passes the field's error state and
message to the input you render. New to the adapters? Start with
[Using MUI with React Hook Form](/docs/react-hook-form-mui).

## Import

```tsx
import { MuiAutocompleteElement } from '@piplup/rhf-adapters/mui-material';
```

## Errors reach the input through renderInput

Autocomplete renders its input through `renderInput`, so that is where the error goes. The
`params` the element passes in include `error`, `helperText` and `required` on top of MUI's usual
input props. Spread them onto your `TextField` and validation messages appear under it:

```tsx
<MuiAutocompleteElement
  control={control}
  name="framework"
  options={['React', 'Vue', 'Svelte']}
  required
  messages={{ required: 'Choose a framework' }}
  renderInput={(params) => <TextField {...params} label="Framework" />}
/>
```

If you set props on the TextField after the spread, such as your own `helperText`, they replace
the ones from `params`.

## What gets stored

| Setup      | Nothing selected | After a selection   |
| ---------- | ---------------- | ------------------- |
| Single     | `null`           | The option          |
| `multiple` | `[]`             | An array of options |

With object options the form holds the whole object, which is often more than an API wants. Use
`transform` to store just an id: `input` maps the stored id back to its option, and `output`
receives MUI's change arguments, `(event, option)`, and returns what to store. The
[`useMuiAutocompleteAdapter` demo](/docs/rhf-adapters/mui-material/hooks/use-mui-autocomplete-adapter)
stores a country code this way.

If you store objects and your default value isn't the same object instance as the matching entry
in `options`, pass `isOptionEqualToValue` so MUI can match them, for example by id.

## Multiple selection

```tsx
<MuiAutocompleteElement
  control={control}
  name="tags"
  multiple
  options={TAGS}
  required
  messages={{ required: 'Add at least one tag' }}
  renderInput={(params) => <TextField {...params} label="Tags" />}
/>
```

The default value is `[]` when you don't set one, and a value that isn't an array is treated as
empty. `required` fails on an empty array, so the message above appears when the user submits
without picking a tag.

`MuiAutocompleteElement` supports all standard props of the MUI Autocomplete component, along with additional adapter-specific props. For a complete list of available Autocomplete properties, refer to the MUI [API documentation](https://mui.com/material-ui/api/autocomplete/).

## Notes

- Use this component when MUI Autocomplete should behave like an `react-hook-form` controlled field.
- For custom autocomplete UIs, build on `useMuiAutocompleteAdapter`.
