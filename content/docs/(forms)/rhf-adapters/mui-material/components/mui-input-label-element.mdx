`MuiInputLabelElement` supports props of the MUI InputLabel component, along with additional adapter-specific props. For a complete list of available InputLabel properties, refer to the MUI [API documentation](https://mui.com/material-ui/api/input-label/).

> The `ref` is forwarded to the underlying `<InputLabel />` component.

## Notes

- Use this component when MUI InputLabel should react to RHF field state.
- For custom input-label UIs, build on `useMuiInputLabelAdapter`.
