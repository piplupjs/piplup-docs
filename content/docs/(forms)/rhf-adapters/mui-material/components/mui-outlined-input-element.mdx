`MuiOutlinedInputElement` supports props of the MUI OutlinedInput component, along with additional adapter-specific props. For a complete list of available InputLabel properties, refer to the MUI [API documentation](https://mui.com/material-ui/api/outlined-input/).

> The `ref` is forwarded to the underlying `<OutlinedInput />` component.

## Notes

- For custom outlined-input UIs, build on `useMuiOutlinedInputAdapter`.
