## Props

<AutoTypeTable path="content/docs/props.ts" name="MuiButtonElementProps" cwd />

`MuiButtonElement` supports all standard props of the MUI Button component, along with additional adapter-specific props. For a complete list of available Button properties, refer to the MUI [API documentation](https://mui.com/material-ui/api/button/).

> The `ref` is forwarded to the underlying `<Button />` component.


## Notes

- Use this component for submit, reset, and form-state-aware button actions.
- For custom button UIs, build on `useMuiButtonAdapter`.
