`MuiInputBaseElement` supports props of the MUI InputBase component, along with additional adapter-specific props. For a complete list of available InputBase properties, refer to the MUI [API documentation](https://mui.com/material-ui/api/input-base/).

> The `ref` is forwarded to the underlying `<InputBase />` component.

## Notes

- For custom InputBase UIs, build on `useMuiInputBaseAdapter`.
