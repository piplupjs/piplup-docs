`MuiSelectElement` is MUI's `Select` connected to React Hook Form. It stores the selected
`MenuItem`'s `value`, or an array of values with `multiple`, and sets the Select's error state when
validation fails. New to the adapters? Start with
[Using MUI with React Hook Form](/docs/react-hook-form-mui).

## Import

```tsx
import { MuiSelectElement } from "@piplup/rhf-adapters/mui-material";
```

## Labels and error messages

MUI's `Select` has no label or helper text of its own; both come from the surrounding
`FormControl`. The element sets the error state, and
[`MuiFormHelperTextElement`](/docs/rhf-adapters/mui-material/components/mui-form-helper-text-element)
renders the message for the same field:

```tsx
<FormControl fullWidth>
  <InputLabel id="role-label">Role</InputLabel>
  <MuiSelectElement
    control={control}
    name="role"
    labelId="role-label"
    label="Role"
    required
    messages={{ required: "Pick a role" }}
  >
    <MenuItem value="viewer">Viewer</MenuItem>
    <MenuItem value="editor">Editor</MenuItem>
  </MuiSelectElement>
  <MuiFormHelperTextElement control={control} name="role" renderOnError />
</FormControl>
```

With `renderOnError`, the helper text renders nothing until the field has an error. Without it,
its children show as a hint while the field is valid and the error replaces them, which is how
`helperText` behaves on a TextField.

Give a single Select a default value of `""`. It counts as empty, so `required` reports an
untouched Select, and MUI renders it as "nothing selected" instead of warning about an
out-of-range value.

## Multiple selection

With `multiple`, the field stores an array of the selected values:

```tsx
<FormControl fullWidth>
  <InputLabel id="languages-label">Languages</InputLabel>
  <MuiSelectElement
    control={control}
    name="languages"
    labelId="languages-label"
    label="Languages"
    multiple
    required
    messages={{ required: "Pick at least one language" }}
  >
    <MenuItem value="en">English</MenuItem>
    <MenuItem value="fr">French</MenuItem>
  </MuiSelectElement>
  <MuiFormHelperTextElement control={control} name="languages">
    Pick every language you speak
  </MuiFormHelperTextElement>
</FormControl>
```

A value that isn't an array, such as a missing default, is shown as no selection. `required`
fails on an empty array. `maxLength` doesn't apply to arrays, so cap the number of choices with a
`validate` function in `rules`; the
[`useMuiSelectAdapter` demo](/docs/rhf-adapters/mui-material/hooks/use-mui-select-adapter) does
exactly that.

## Notes

- For custom select UIs, build on `useMuiSelectAdapter`. Unlike the element, the hook returns
  `helperText`, which holds the error message when you pass `composeHelperText`.
- To store something other than the selected `value`, use `transform`.
