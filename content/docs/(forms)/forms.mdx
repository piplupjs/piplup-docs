`react-hook-form` handles state and validation well, but wiring each field to it means the same
`Controller` boilerplate every time: map the field state onto the component's props, translate its
change event back, and surface the error. These two packages do that mapping once.

## Packages

## Which one do I need?

`@piplup/rhf-adapters` depends on `@piplup/rhf-core`, so installing the adapters gives you both. Use
core on its own only when you are adapting components the adapters don't cover.

Every adapter comes in two forms: a **hook** that returns the props to spread onto your own
component, and an **element** that renders the component for you. The hook is the escape hatch when
the element's defaults don't fit.

## New to these packages?

Start with [Using MUI with React Hook Form](/docs/react-hook-form-mui): it builds the same form with
a `Controller` and with the adapters, then covers validation, default values and the element for
every MUI input.
