---
title: useMuiSelectAdapter
description: Returns props that connect an MUI Select to React Hook Form, including multiple selection, for building a select with its own label and helper text.
---

`useMuiSelectAdapter` connects an MUI `Select` to a React Hook Form field and returns props you spread onto it. It's what [`MuiSelectElement`](/docs/rhf-adapters/mui-material/components/mui-select-element) uses internally.

`Select` on its own has no label or helper text, so a complete field needs a `FormControl`, an `InputLabel` and a `FormHelperText` around it. The element doesn't render those for you. Use the hook to build that whole field once, with the error message wired in.

## Import

```tsx
import { useMuiSelectAdapter } from "@piplup/rhf-adapters/mui-material";
```

## Usage

A multiple select that needs at least one and at most three languages. The helper text switches to the error message when a rule fails.

## How it works

**Single vs multiple.** Pass `multiple` to the hook, not only to `Select`; the hook returns it so it reaches `Select` when you spread. With `multiple`, a field value that isn't an array (such as `undefined`) is passed to `Select` as `[]`. Without it, the field value is passed through unchanged.

**Stored value.** On change, the hook stores `event.target.value`: the selected `MenuItem` value, or the array of selected values with `multiple`. Use `transform.output` to store something else.

**Validation.** `required` fails for an empty string and for an empty array, so it works for both modes. React Hook Form's `minLength` and `maxLength` don't apply to arrays, so limit the number of selections with `rules.validate`, as the demo does.

**Errors and helper text.** `Select` accepts `error` but has no `helperText` prop. Render the returned `helperText` in a `FormHelperText`, and put `error` on the `FormControl` so the label and helper text turn red too. With `composeHelperText: true`, `helperText` is the field's error message, falling back to your `helperText` when there's no error.

<Callout type="warn">
  For a single select, give the field a default value such as `""` in `useForm`'s `defaultValues`. Without one, `Select` receives `undefined` at first, which MUI treats as uncontrolled, and logs a warning when a value is chosen.
</Callout>

<Callout type="warn">
  `helperText` isn't a `Select` prop. Remove it from the returned object before spreading, as the demo and the element do.
</Callout>
