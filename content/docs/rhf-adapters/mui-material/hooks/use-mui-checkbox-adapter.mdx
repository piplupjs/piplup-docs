title: useMuiCheckboxAdapter
description: Returns props that connect an MUI Checkbox to React Hook Form, storing checked values in an array, with custom checked and indeterminate logic.

`useMuiCheckboxAdapter` connects one MUI `Checkbox` to a React Hook Form field and returns props you spread onto it. It's what [`MuiCheckboxElement`](/docs/rhf-adapters/mui-material/components/mui-checkbox-element) uses internally.

Use the element for plain checkbox lists. Reach for the hook when one component should own a whole group (label, options, error text), or for checkboxes whose state isn't simply "is my value in the array", such as a "select all" box that controls the rest.

## Import

```tsx
import { useMuiCheckboxAdapter } from "@piplup/rhf-adapters/mui-material";
```

## Usage

The "All channels" box is checked when every channel is selected, indeterminate when some are, and selects or clears all of them on click. Uncheck everything and submit to see the required message, which the same hook provides as `helperText`.

## How it works

**`value` is required.** Each checkbox stands for one value. Without a `value`, the hook throws `` `value` prop is required when using type as "checkbox". `` This applies to single on/off checkboxes too (see below).

**The field holds an array.** By default, checking a box adds its `value` to the field's array and unchecking removes it. When the last value is removed, the field becomes `undefined`, not an empty array. Several checkboxes with the same `name` build one array together. Give them the same rules, as the demo does with `sharedProps`.

**Checked state.** The returned `checked` is `true` when the field is an array that contains `value`. Values are compared as strings, so a field value of `"2"` checks a box with `value={2}`. Pass a `checked` function to decide yourself. It receives the field value (after `transform.input`) and returns a boolean. `indeterminate` works the same way and is only applied when you pass it as a function.

**Transforms.** `transform.output` receives `(event, checked, previousValue)`, where `previousValue` is the current field value. Whatever it returns is stored. Your `transform` replaces the default for each key you set, so overriding `output` alone, as the demo's "select all" box does, keeps the default `input`.

**Single on/off checkbox.** To store `true`/`false` instead of an array, give the box a `value`, decide `checked` yourself and store the `checked` flag:

```tsx
const adapter = useMuiCheckboxAdapter<unknown, FormValues, "terms", HTMLButtonElement>({
  control,
  name: "terms",
  value: true,
  required: true,
  checked: (value) => value === true,
  transform: {
    output: (_event: React.ChangeEvent<HTMLInputElement>, checked: boolean) => checked,
  },
});
```

React Hook Form treats `false` as missing, so `required` here means "must be checked".

**Validation.** `required` fails when no box in the group is checked, because the field is then `undefined`. `minLength` and `maxLength` don't apply to arrays in React Hook Form, so use `rules.validate` to require "at least two" or "at most three".

**Inside a `FormControl`.** If you don't pass `disabled` or `required`, the hook takes them from the surrounding MUI `FormControl`.

**Errors.** A checkbox can't show a message. The hook returns `error` and `helperText`; render them in a `FormControl` and `FormHelperText` around the group. With `composeHelperText: true`, `helperText` is the field's error message, falling back to your `helperText` when there's no error.

<Callout type="warn">
  `Checkbox` has no `error` or `helperText` props. Remove them before spreading the result. Remove `required` as well when the checkbox sits in a `FormControlLabel`: otherwise the label shows an asterisk next to every option.
</Callout>

<Callout type="warn">
  Keep option values the same type as the stored values. Checked state compares values as strings, but unchecking removes values with strict equality. If the field holds `"2"` and the box has `value={2}`, it shows as checked but clicking it can't remove `"2"`.
</Callout>
