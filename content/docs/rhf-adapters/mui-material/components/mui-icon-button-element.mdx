`MuiIconButtonElement` supports props of the MUI IconButton component, along with additional adapter-specific props. For a complete list of available IconButton properties, refer to the MUI [API documentation](https://mui.com/material-ui/api/icon-button/).

> The `ref` is forwarded to the underlying `<IconButton />` component.


## Notes

- For custom icon button UIs, build on `useMuiIconButtonAdapter`.
