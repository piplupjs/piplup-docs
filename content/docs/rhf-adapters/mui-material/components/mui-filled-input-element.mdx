`MuiFilledInputElement` supports all standard props of the MUI FilledInput component, along with additional adapter-specific props. For a complete list of available FilledInput properties, refer to the MUI [API documentation](https://mui.com/material-ui/api/filled-input/).

> The `ref` is forwarded to the underlying `<FilledInput />` component.

## Notes

- For custom filled-input UIs, build on `useMuiFilledInputAdapter`.
