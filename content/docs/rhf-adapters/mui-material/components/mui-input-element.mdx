## Props

<AutoTypeTable path="content/docs/props.ts" name="MuiInputElementProps" cwd />

`MuiInputElement` supports props of the MUI Input component, along with additional adapter-specific props. For a complete list of available Input properties, refer to the MUI [API documentation](https://mui.com/material-ui/api/input/).

> The `ref` is forwarded to the underlying `<Input />` component.

## Notes

- Use this component for standard MUI input fields managed by RHF.
- For custom input UIs, build on `useMuiInputAdapterProps`.
