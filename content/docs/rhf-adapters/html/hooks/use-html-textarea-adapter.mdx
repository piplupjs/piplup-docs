---
title: useHtmlTextareaAdapter
description: Returns normalized textarea props for building custom textarea components connected to React Hook Form.
---

`useHtmlTextareaAdapter` exposes the value, events, and field-state-aware props needed to build a custom textarea component on top of React Hook Form.

## Import

```tsx
import { useHtmlTextareaAdapter } from "@piplup/rhf-adapters/html";
```

## Notes

- Use this hook when a custom multiline input should still participate in React Hook Form validation and state management.
- The hook is built on top of `useControllerAdapter`.
- It is a textarea-specific variant of the HTML input adapter with checkbox- and type-specific props removed.
