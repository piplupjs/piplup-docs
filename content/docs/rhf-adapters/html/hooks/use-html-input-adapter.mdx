---
title: useHtmlInputAdapter
description: Returns normalized input props for building custom HTML input components connected to React Hook Form.
---

`useHtmlInputAdapter` returns value, event handlers, and field-state-aware props for custom input components that should behave like React Hook Form-controlled fields.

## Import

```tsx
import { useHtmlInputAdapter } from "@piplup/rhf-adapters/html";
```

## Notes

- Use this hook for bespoke input components that still need React Hook Form registration and value synchronization.
- The hook is built on top of `useControllerAdapter`.
- `transform`, `checked`, and `indeterminate` are useful when DOM values do not match your stored form value exactly.
