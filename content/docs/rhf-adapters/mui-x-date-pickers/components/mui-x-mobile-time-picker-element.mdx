`MuiXMobileTimePickerElement` supports all standard props of the MUI X MobileTimePicker component, along with additional adapter-specific props. For a complete list of available MobileTimePicker properties, refer to the MUI X Date Pickers [API documentation](https://mui.com/x/api/date-pickers/mobile-time-picker/).

> The `ref` is forwarded to the underlying `<MobileTimePicker />` component.

## Notes

- For custom mobile time pickers, build on `useMuiXMobileTimePickerAdapter`.
