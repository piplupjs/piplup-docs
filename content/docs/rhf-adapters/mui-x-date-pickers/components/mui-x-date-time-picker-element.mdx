`MuiXDateTimePickerElement` supports all standard props of the MUI X DateTimePicker component, along with additional adapter-specific props. For a complete list of available DateTimePicker properties, refer to the MUI X Date Pickers [API documentation](https://mui.com/x/api/date-pickers/date-time-picker/).

> The `ref` is forwarded to the underlying `<DateTimePicker />` component.

## Notes

- For custom date-time pickers, build on `useMuiXDateTimePickerAdapter`.
