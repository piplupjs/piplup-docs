`MuiXStaticDatePickerElement` supports all standard props of the MUI X StaticDatePicker component, along with additional adapter-specific props. For a complete list of available StaticDatePicker properties, refer to the MUI X Date Pickers [API documentation](https://mui.com/x/api/date-pickers/static-date-picker/).

> The `ref` is forwarded to the underlying `<StaticDatePicker />` component.

## Notes

- For custom static date pickers, build on `useMuiXStaticDatePickerAdapter`.
