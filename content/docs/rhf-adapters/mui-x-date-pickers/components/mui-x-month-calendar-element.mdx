`MuiXMonthCalendarElement` supports all standard props of the MUI X MonthCalendar component, along with additional adapter-specific props. For a complete list of available MonthCalendar properties, refer to the MUI X Date Pickers [API documentation](https://mui.com/x/api/date-pickers/month-calendar/).

> The `ref` is forwarded to the underlying `<MonthCalendar />` component.

## Notes

- For custom month calendars, build on `useMuiXMonthCalendarAdapter`.
