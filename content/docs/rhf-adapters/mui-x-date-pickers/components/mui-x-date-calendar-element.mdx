`MuiXDateCalendarElement` supports all standard props of the MUI X DateCalendar component, along with additional adapter-specific props. For a complete list of available DateCalendar properties, refer to the MUI X Date Pickers [API documentation](https://mui.com/x/api/date-pickers/date-calendar/).

> The `ref` is forwarded to the underlying `<DateCalendar />` component.

## Notes

- For custom calendar UIs, build on `useMuiXDateCalendarAdapter`.
