`MuiXStaticTimePickerElement` supports all standard props of the MUI X StaticTimePicker component, along with additional adapter-specific props. For a complete list of available StaticTimePicker properties, refer to the MUI X Date Pickers [API documentation](https://mui.com/x/api/date-pickers/static-time-picker/).

> The `ref` is forwarded to the underlying `<StaticTimePicker />` component.

## Notes

- For custom static time pickers, build on `useMuiXStaticTimePickerAdapter`.
