`MuiXTimePickerElement` supports all standard props of the MUI X TimePicker component, along with additional adapter-specific props. For a complete list of available TimePicker properties, refer to the MUI X Date Pickers [API documentation](https://mui.com/x/api/date-pickers/time-picker/).

> The `ref` is forwarded to the underlying `<TimePicker />` component.

## Notes

- For custom time pickers, build on `useMuiXTimePickerAdapter`.
