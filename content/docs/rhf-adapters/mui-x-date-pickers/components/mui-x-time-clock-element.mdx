`MuiXTimeClockElement` supports all standard props of the MUI X TimeClock component, along with additional adapter-specific props. For a complete list of available TimeClock properties, refer to the MUI X Date Pickers [API documentation](https://mui.com/x/api/date-pickers/time-clock/).

> The `ref` is forwarded to the underlying `<TimeClock />` component.

## Notes

- For custom time-clock UIs, build on `useMuiXTimeClockAdapter`.
