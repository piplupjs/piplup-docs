`useMuiXMultiSectionDigitalClockAdapter` connects a field to React Hook Form and returns props you spread onto MUI X's `MultiSectionDigitalClock`, which shows one scrollable column per section (hours, minutes, seconds, AM/PM). It's what [`MuiXMultiSectionDigitalClockElement`](/docs/rhf-adapters/mui-x-date-pickers/components/mui-x-multi-section-digital-clock-element) uses internally.

The element shows the columns only and drops the error message. Use the hook when the clock is inline in your form and you want a separate message for each column's rule, for example one for minutes and one for seconds.

## Import

```tsx
import { useMuiXMultiSectionDigitalClockAdapter } from "@piplup/rhf-adapters/mui-x-date-pickers";
```

## Usage

This `DepartureClock` allows departures every 5 minutes, at :00 or :30 seconds. The columns only list valid values, so submit without picking a time to see the required error below the clock.

## How it works

Validation and default messages are the same as [`useMuiXTimePickerAdapter`](/docs/rhf-adapters/mui-x-date-pickers/hooks/use-mui-x-time-picker-adapter#how-it-works). The result is shaped like the [`useMuiXTimeClockAdapter`](/docs/rhf-adapters/mui-x-date-pickers/hooks/use-mui-x-time-clock-adapter#how-it-works) one: take `error`, `helperText` and `required` out before spreading, render the message yourself, and expect the field to become touched when focus leaves the columns.

**One rule per column.** `MultiSectionDigitalClock` checks each column with the matching view: hour options with `shouldDisableTime(value, "hours")`, minute options with `"minutes"` and second options with `"seconds"`. Validation uses the same three views, so a rule written for one view disables options in that column and reports the matching key:

| Rule in `shouldDisableTime` | Disables options in | Message key |
| --- | --- | --- |
| `view === "hours"` | hours column | `shouldDisableTime-hours` |
| `view === "minutes"` | minutes column | `shouldDisableTime-minutes` |
| `view === "seconds"` | seconds column | `shouldDisableTime-seconds` |

Validation reports only the first failing check, in the order hours, minutes, seconds, then `minutesStep`. In the example, a value at 08:07:15 reports the seconds message, not the `minutesStep` one.

**`timeSteps` and `minutesStep` are separate.** `timeSteps` is a `MultiSectionDigitalClock` prop that only controls which options each column lists. `minutesStep` is a validation prop that the hook returns, so it also disables minute options. The example sets both so the minutes column and validation agree.
