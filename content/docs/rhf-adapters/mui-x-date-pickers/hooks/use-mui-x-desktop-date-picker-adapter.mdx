`useMuiXDesktopDatePickerAdapter` returns React Hook Form props for MUI X's `DesktopDatePicker`. It's what [`MuiXDesktopDatePickerElement`](/docs/rhf-adapters/mui-x-date-pickers/components/mui-x-desktop-date-picker-element) uses internally.

Use the element for most forms. Use the hook when you build desktop date fields that work together, such as a check-in and check-out pair where one field's limits come from the other.

## Import

```tsx
import { useMuiXDesktopDatePickerAdapter } from "@piplup/rhf-adapters/mui-x-date-pickers";
```

## Usage

The check-out field reads the check-in value with `useWatch` and passes it as `minDate` and `maxDate`, so a stay must be 1 to 14 nights. Pick a check-in date, then type a check-out date before it and submit.

## How it works

This hook calls [`useMuiXDatePickerAdapter`](/docs/rhf-adapters/mui-x-date-pickers/hooks/use-mui-x-date-picker-adapter) with the same props and returns its result unchanged. Value handling, validation messages and the text field wiring are documented there.

The difference is the component. `DatePicker` chooses the desktop or mobile layout with a `@media (pointer: fine)` query. `DesktopDatePicker` always opens the calendar in a popover next to the field on every device, including touch screens where `DatePicker` would open a dialog.

**Limits from another field.** The validation rule is rebuilt on every render from the current `minDate` and `maxDate`. When check-in changes, the check-out field re-renders with new limits, and the next validation of check-out uses them. If check-in is still empty, `minDate` and `maxDate` are `undefined` and the hook falls back to the `LocalizationProvider` defaults (1900-01-01 and 2099-12-31).

<Callout type="warn">
  Changing check-in does not re-validate check-out on its own. A check-out error stays visible until check-out changes or the form is submitted. Call `trigger("checkOut")` in an effect after check-in changes if you need it immediately.
</Callout>

**Errors and blur.** The text field receives `error`, `helperText` and `onBlur` through `slotProps.textField`, and closing the popover also counts as a blur.
