title: useMuiXDatePickerAdapter
description: Returns adapter props for building custom MUI X DatePicker integrations with React Hook Form.

`useMuiXDatePickerAdapter` connects a field to React Hook Form and returns props you spread onto MUI X's `DatePicker`. It's what [`MuiXDatePickerElement`](/docs/rhf-adapters/mui-x-date-pickers/components/mui-x-date-picker-element) uses internally.

Use the element for most forms. Reach for the hook when you want to build your own date field component, for example to bake in project-wide rules, wrap the picker in extra layout, or render a different picker variant with the same form wiring.

## Import

```tsx
import { useMuiXDatePickerAdapter } from "@piplup/rhf-adapters/mui-x-date-pickers";
```

This `AppointmentField` only accepts future weekdays and uses its own error messages. Submit the form empty, or pick a weekend date by typing it, to see the validation.

The hook must run inside a `LocalizationProvider`, because it reads the date adapter to validate values and apply the default `minDate`/`maxDate`.

## How it works

**Value.** The field value is passed to the picker as-is, with `undefined` converted to `null` so the picker stays controlled. Pass `transform` if your form stores something other than a date object, such as an ISO string.

**Validation.** The hook runs MUI X's own `validateDate` against `minDate`, `maxDate`, `disablePast`, `disableFuture`, `shouldDisableDate`, `shouldDisableMonth` and `shouldDisableYear`. Any failure becomes a React Hook Form error, so it blocks submission like any other rule. Empty values pass this check; add `required` to reject them.

Each failure has a default message, which you can replace through `messages`:

| Key | Default message |
| --- | --- |
| `required` | Please fill out this field. |
| `invalidDate` | Date is not a valid date |
| `disablePast` | Past date is not allowed |
| `disableFuture` | Future date is not allowed |
| `minDate` | Date must be later than the minimum allowed date |
| `maxDate` | Date should be earlier than the maximum allowed date |
| `shouldDisableDate` | Date is not allowed |
| `shouldDisableMonth` | Month is not allowed |
| `shouldDisableYear` | Year is not allowed |

Messages other than `required` can also be functions that receive the date, e.g. `` minDate: (date) => `${date.format("D MMM")} is too early` ``.

<Callout type="warn">
  If you pass your own `rules.validate`, the built-in date validation above is not added. Validate dates yourself in that case.
</Callout>

**Errors and blur.** The returned `slotProps.textField` sets `error` and `helperText` from the field state, and calls React Hook Form's `onBlur` so the field is marked as touched. Your own `slotProps.textField` (an object or a function) is merged in: an error message takes priority over your `helperText`, which shows when the field is valid. Closing the picker also counts as a blur.

Set `composeHelperText: true` to show the error message as the helper text, as the element does. Without it, only the `error` state is applied.
