## Introduction

**Piplup** is a collection of small, typed React libraries. Each one solves a single problem, so you
install what you need and nothing else:

- **[React Hook Form adapters for MUI and native inputs](/docs/forms)**: connect MUI TextField,
  Select, Autocomplete, the MUI X date pickers and plain HTML inputs to `react-hook-form` without
  writing a `Controller` for every field.
- **[Role and permission-based access control for React](/docs/access-control)**: show or hide UI by
  the signed-in user's roles and permissions, with wildcard grants and typed permission names.
- **[Cache busting for deployed React and Vite apps](/docs/cache-busting)**: detect that a new build
  has shipped and reload clients that are still running the old bundle.
- **[React utility hooks](/docs/utilities)**: `useLocalStorage`, `useEventCallback`, `useForkRef`
  and the other helpers the packages above are built on.
